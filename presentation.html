Problem Statement

  • Lack of Awareness: Users struggle to keep track of daily small expenses leading to overspending.
  • Manual Effort: Traditional tracking involves tedious manual entry and complicated spreadsheets.
  • No Predictive Insights: Existing tools only show past data without offering future alerts or smart savings advice.

Our Solution

A comprehensive web application that automates financial tracking while providing actionable intelligence.

  • Seamless Authentication (Email & Google)
  • Interactive & Real-time Dashboards
  • Intelligent Alerts for high-spending patterns
  • Cloud-synced data for accessibility everywhere

Technology Stack

Modern, Scalable, and Fast

Frontend

  • React.js: Component-based UI formulation
  • Tailwind CSS (v4): Rapid, responsive styling
  • Recharts: Dynamic, interactive data visualization
  • Vite: Ultra-fast frontend tooling

Backend & Database

  • Node.js & Express.js: REST API architecture
  • Firebase Firestore: NoSQL real-time cloud database
  • Firebase Auth: Secure user authentication

System Architecture

1. Client Layer: React SPA communicating via HTTP requests.

2. API Layer: Express.js handling routing and business logic.

3. Authentication Layer: Firebase Auth tokens verified by backend.

4. Data Layer: Firestore storing Collections for Users and Transactions.

5. AI/Insights Engine: Rule-based and predictive models generating alerts on recent spending.

Database Design (Firestore)

Collections:

  • users - Stores user profiles and preferences.
  • transactions - Documents include:
    • userId (Reference)
    • title (String)
    • amount (Number)
    • category (String)
    • type ('income' or 'expense')
    • date (Timestamp)

Predictive & Smart Insights

How our app goes beyond normal tracking:

  • Categorical Analysis: Detects which category consumes the most budget incrementally.
  • Survival Prediction: Estimates how many days current funds will last at the current burn rate.
  • Intelligent Alerts: High-spending warnings triggered dynamically when thresholds are breached.

Future Enhancements

  • Integration with Open Banking APIs for automatic syncing
  • Receipt scanning utilizing Optical Character Recognition (OCR)
  • Advanced Deep Learning models for precise future expense forecasting
  • Budget sharing and family accounts
